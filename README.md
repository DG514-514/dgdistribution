# DG Distribution website

Static site for **dgdistribution.ca**, hosted for free on GitHub Pages.

- `index.html`: page content (services, brands, story, contact)
- `styles.css`: design
- `script.js`: menu, scroll animations, inquiry form. **Contact details (email, phone, location) are set at the top of this file.**
- `img/`: logo and emblem

The inquiry form opens the visitor's email app with their inquiry filled in, addressed to the contact email in `script.js`.
